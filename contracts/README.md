# Contracts v0 (draft, freeze by end of Phase 1)

Source of truth: [`models.py`](models.py) (Pydantic v2). JSON Schemas in [`schemas/`](schemas/) are generated by
`uv run python scripts/export_contracts.py`; CI fails if they are stale. `web/` should generate its TypeScript
types from these schemas (e.g. `json-schema-to-typescript`) rather than hand-writing them.

## Events (SSE)

`GET /api/runs/{id}/events` streams `text/event-stream`; each `data:` line is one `Event` JSON object
(discriminated by `type`). Every event has `v`, `run_id`, `seq` (strictly increasing), `ts` (ISO 8601 UTC).
The SSE `id:` field equals `seq`, so a client can reconnect with `Last-Event-ID` and receive only later events.

| type | when | key fields |
|---|---|---|
| `run.started` | first event | `source` (name, size, sha256, data_label), `mode` live/replay, `runner`, `models` |
| `memory.hit` | a learned mapping/normalizer/threshold set is reused | `kind`, `fingerprint`, `saved_at` |
| `schema.proposed` | tier 1 mapping or tier 2 normalizer proposed | `tier`, `attempt`, `mapping` or `code_id` |
| `schema.validated` | deterministic checks ran | `ok`, `checks[]`, `n_channels`, `n_cycles`, `n_rows` |
| `schema.needs_confirmation` | validation passed with low confidence or failed twice | `reason` |
| `llm.call` | every model call | `role`, `model`, `purpose`, `tokens_in/out`, `latency_ms`, `cost_usd`, `cached` |
| `code.generated` | planner wrote code | `code_id`, `attempt`, `sha256`, `code` |
| `sandbox.started` / `sandbox.finished` | per shard | `code_id`, `shard`/`n_shards`, `ok`, `exit_code`, `stdout_tail`, `stderr_tail`, `artifacts`, `operation_id` |
| `repair.attempt` | a sandbox run failed and the planner is repairing it | `attempt`/`max_attempts`, `failed_code_id`, `error_summary` |
| `analysis.progress` | shard or channel progress | `done`, `total`, `unit` |
| `thresholds.proposed` | agent proposes grade bins | `thresholds` (with `rationale`) |
| `results.ready` | results JSON can be fetched | `summary` |
| `verify.claim_failed` | a report sentence cites a number not in the results | `sentence`, `claim`, `reason`, `action` |
| `verify.summary` | verification done | counts |
| `report.ready` | report can be fetched | `formats` |
| `run.failed` / `run.finished` | terminal | `stage`+`error` / totals (duration, tokens, cost) |

## HTTP API

| Method and path | Body | Response |
|---|---|---|
| `GET /api/samples` | | `SampleInfo[]` |
| `POST /api/runs` | multipart `file` **or** JSON `{"sample_id": str, "mode": "live" or "replay"}` | `RunCreated` (201) |
| `GET /api/runs/{id}/events` | | SSE stream of `Event` |
| `GET /api/runs/{id}/results` | | `BatchResults` (409 until `results.ready`) |
| `GET /api/runs/{id}/channels/{channel_id}` | | `{channel: ChannelResult, curves: {cycle: {t, v, i}}}` (downsampled ≤ 2,000 points/cycle) |
| `POST /api/runs/{id}/regrade` | `RegradeRequest` | `BatchResults` (deterministic, no LLM call) |
| `GET /api/runs/{id}/report?format=md` | | `text/markdown` (`pdf` later if time allows) |
| `GET /api/runs/{id}/artifacts/{path}` | | code, logs and shard outputs that back every number (provenance links) |
| `POST /api/replay/{sample_id}` | | `RunCreated` for a replay of a recorded run (zero LLM calls) |
| `GET /api/memory` | | learned formats and saved thresholds (for the "learned formats" view) |

Errors use `ApiError` with HTTP 4xx/5xx. Uploads: max 200 MB; allowed extensions `.csv .txt .tsv .xlsx .xls .mat .h5 .parquet .zip`.
